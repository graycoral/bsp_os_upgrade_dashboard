# 개발 빌드·테스트 로그 처리

이 규칙은 에이전트가 수행하는 개발 빌드·테스트 검증에 적용한다.

- 실행마다 고유한 `.local-reports/<run-id>/` 아래 파일에 전체 stdout과 stderr를 직접 리디렉션한다. 전체 출력을 모델이나 도구 출력에 쏟아내지 않는다.
- 명령의 실제 종료 코드를 즉시 확보하고 파이프라인에서 잃지 않는다.
- 성공 시 명령, 종료 코드, 확인 가능한 경우 건수, 로그 경로만 읽고 보고한다. 실패 시 오류·실패 주변의 제한된 문맥을 검색하고 필요할 때만 범위를 점진적으로 넓힌다. 확인하지 않은 건수나 근거를 만들지 않는다.
- 전체 원본 로그와 실패한 시도를 로컬에 보존하고 덮어쓰지 않는다. 원본 로그, 상세 결과(JSON/XML), 추적 정보, 스크린샷 및 압축 사본은 로컬에만 두며 `git add`나 `git add -f`로 Git에 올리지 않는다. `.local-reports`는 이미 Git에서 제외되어 있다.
- `docs/testing/runs/`에 커밋하는 요약에는 명령, 상태, 필요한 실패 메모와 경로를 간결하게 기록할 수 있다. 경로는 로컬 전용이며 저장소에 포함되지 않음을 명시한다. 기존 추적 이력은 그대로 보존한다.

이 규칙은 제품 실행 로그나 빌드·테스트 명령 자체를 변경하지 않는다.

## 구현 경계

- `apps/web/src/motion.css`: 공통 버튼, 진행률, 공통 모달. `main.tsx`는 progress의 transform과 입력 방식 표식만 변경한다.
- `gui_test/web/motion.css`, `TestPage.tsx`: 독립 배포에도 같은 피드백과 키보드 예외를 제공한다.
- `workflow_diagram/web/diagram.css`, `DiagramTab.tsx`, `viewport.ts`: 독립 폴더 경계를 유지한다. 이동 화살촉은 신선한 실행 경로에서만 동작하고 일시정지/비활성/모션 줄이기를 유지한다.
- `@starting-style` 미지원 브라우저에서는 모달이 즉시 표시되는 점진적 향상이다. 닫기는 조건부 unmount로 즉시 처리한다. 키보드 포커스 트랩과 원래 버튼 복원을 유지한다.
- 생성물 `.runtime-gui/`를 ignore에 추가한다. 기존 `.local-reports/`, 빌드 파일, 의존성, DB ignore는 유지한다. 사용자가 참고한 다이어그램 HTML·생성 원본은 삭제하지 않는다.

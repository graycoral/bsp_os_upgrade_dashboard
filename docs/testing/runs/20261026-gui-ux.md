## 검증 도구의 최초 실패와 재확인

제품 동작 실패로 확인되지 않은 다음 도구 문제를 제품 결함/새 회귀 ID로 승격하지 않는다. 기대 조건을 삭제하지 않고 도구 입력·탐색·동작만 수정했다.

1. PowerShell에서 `node -e`의 따옴표가 제거되어 SyntaxError. 표준 입력으로 실행하도록 수정.
2. PowerShell 파이프 인코딩으로 한글 locator가 `??`가 되어 시간 초과. JS 문자열을 ASCII Unicode escape로 전달하여 해결.
3. 빈 검색 안내에 하위 초기화 버튼 텍스트가 포함돼 정확 일치 문장 locator가 실패. [초기 관찰](20261026-gui-ux-evidence/inspection-initial.json)의 `empty:false`를 보존한다. 실제 빈 결과 영역을 확인하도록 수정한 후 `empty:true`, 초기화 후 기존 선택 유지 확인.
4. 단일 포인터 이동만으로 dragover가 생성되지 않아 삽입선 검사 시간 초과. 대상 hover를 두 번 수행한 후 실제 삽입선 1개와 취소/동일 위치 순서 보존 확인. [최종 관찰](20261026-gui-ux-evidence/inspection-final.json).
5. 신규 CSV 행의 CRLF를 `git diff --check`가 trailing whitespace로 보고. 신규 3개 행을 LF로 저장해 해소했으며 과거 결과 행은 원래 줄바꿈까지 그대로 보존했다.

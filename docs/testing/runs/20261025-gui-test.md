## 최초 실패와 수정

- REG-0009: 빈 프로파일의 `connection` 접근에서 KeyError 발생. Pydantic 검증을 통해 422 응답으로 변경하고 API 재현 시험을 유지했다.
- REG-0010: 탐색 시험에서 정렬상 첫 항목을 Dual로 잘못 가정. 특정 path를 선택해 분류/충돌 검증을 유지했다.
- 브라우저의 범용 Playwright 다운로드는 환경상 잘못된 ZIP을 반환했다. 별도로 설치한 Chromium 153 실행 파일을 `BSP_BROWSER_EXECUTABLE`로 지정해 검증했다. 제품 lockfile에 해당 보조 패키지는 추가하지 않았다.
- 화면 검토에서 기존 전역 label CSS의 flex 방향 간섭을 확인해 GUI 범위 내 row 방향을 명시했다. 이후 브라우저 전체 재검증을 수행했다.

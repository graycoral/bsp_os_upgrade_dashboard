# PORT-NNN · 기능 이름

빈 양식이다. 실제 기능 안내서는 원본 `docs/porting/PORT-NNN.md`에 작성한다. 빈 값이 남은 양식을 이식 준비 완료로 전달하지 않는다.

## 목적과 기준

- 사용자에게 달라지는 동작 / 범위:
- 관련 요구사항 ID·설계 문서 절:
- 원본 저장소 / 기준 커밋(전체 해시) / 대상 코드 커밋(전체 해시):
- 선행 PORT·필수 커밋·의존성 버전:
- 실제 시험한 코드 기준 / 대상과의 차이:
- 전달 방식: 고정 Git 커밋 / 선택 패치(생성 범위·파일·SHA256):

## 재사용 코드와 회사 연결

| 원본 파일·함수·컴포넌트 | 변경 이유·유지할 동작 | 방식: 신규 모듈/패치/회사 조정 | 의존 코드·관련 시험 |
|---|---|---|---|

회사 대응 위치는 회사 `COMPANY_MAP.md`에서 확인한다. 알 수 없는 회사 구조는 추정하지 않는다.

- API·저장 형식·설정·의존성 영향(없으면 없음):
- 이전 데이터 호환·이전 절차·복원 방법(해당 여부 포함):
- 회사에서 확인할 접점·보존할 기능·충돌 예상:
- 관련 원문 링크(계약 필드 목록 복제 금지):

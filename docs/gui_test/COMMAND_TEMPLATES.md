# 공통 TC 실행 명령 템플릿

TC마다 명령 전체를 입력하지 않고, Single/Dual 공통 명령을 한 번 저장한 뒤 TC 이름과 COM 값을 자동 치환합니다. Windows 단독 GUI와 Dashboard의 공통 Test 현황 화면에서 사용합니다.

현재는 **Mock 실행 및 인자 미리보기**입니다. 템플릿에 Python 명령을 저장해도 임의 프로그램을 실행하지 않습니다. 실제 Linux TC 호출/취소/프로세스 확인은 승인된 Runner Adapter 연결 후에 가능합니다.

## 설정 방법

1. 실행 명령 설정을 열고 프로파일 이름을 입력합니다.
2. Single/Dual 각각 **한 줄에 인자 하나씩** 작성합니다. 첫 줄은 실행 파일이며, 이후 줄은 고정 인자 또는 치환 변수입니다.
3. 명령을 저장하고 사용할 프로파일을 선택합니다.
4. TC와 보드/COM을 선택해 명령 미리보기로 최종 argv 배열을 확인합니다.
5. Preflight 후 Mock 테스트를 시작합니다. 실행 중 프로파일을 수정해도 진행 중인 Run은 시작 당시 명령과 COM을 사용합니다.

아래는 문법 설명을 위한 예시이며 실제 회사 명령의 플래그를 확정한 것이 아닙니다. 실제 성공한 명령의 **고정 부분은 그대로**, 바뀌는 TC 값만 변수로 바꾸세요.

Single 예시:

```text
python
run_tests.py
--test
{tc_name}
--port
{com_a}
```

TC 경로가 `network/03_link.py`, COM이 `COM3`이면 다음 배열로 해석합니다.

```json
["python", "run_tests.py", "--test", "03_link", "--port", "COM3"]
```

TC 파일 자체를 실행하는 방식이라면 다음처럼 설정합니다.

```text
python
{tc_path}
--port
{com_a}
```

Dual 명령에는 기존 명령에서 두 번째 COM을 받는 인자 자리에 `{com_b}`를 추가합니다. 옵션 이름·인자 순서는 실제 명령에 맞춰야 합니다. 공백이 있는 Python 경로도 한 줄로 입력하며, argv 입력에는 경로를 감싸는 따옴표를 추가하지 않습니다.

## 치환 변수

| 변수 | 의미 | 예 |
|---|---|---|
| `{tc_name}` | TC 파일명에서 마지막 확장자를 제외한 이름 | `03_link` |
| `{tc_file}` | 확장자를 포함한 파일명 | `03_link.py` |
| `{tc_path}` | 카탈로그에 저장된 TC 경로(현재 데모는 TC 루트 기준 상대 경로) | `network/03_link.py` |
| `{com_a}` | 선택한 Board A의 COM | `COM3` |
| `{com_b}` | Dual의 Board B COM | `COM4` |

TC 변수 3종 중 **하나를 정확히 한 번** 사용합니다. Single은 `{com_a}` 한 번, Dual은 `{com_a}`와 `{com_b}`를 각각 한 번 사용합니다. 변수는 인자 하나 전체여야 하며 `--test={tc_name}`처럼 고정 문자열과 합치지 않습니다. 필요한 옵션과 값은 별도 줄로 작성합니다.

명령 템플릿은 셸 스크립트가 아닙니다. 파이프·리다이렉션·환경변수 확장이나 명령 치환을 수행하지 않습니다. 미등록 변수, 잘못된 괄호, TC/COM 누락·중복 및 잘못된 Single/Dual 구성을 거부합니다.

## 보존과 검증

- 프로파일은 해당 모드의 로컬 SQLite에 저장합니다. Windows 단독과 Dashboard 프로파일은 서로 자동 공유하지 않습니다.
- 저장된 명령은 버전 해시로 확인합니다. 다른 화면에서 수정됐다면 이전 버전으로 새 Run을 시작하지 못하며 다시 불러와 확인해야 합니다.
- Run에는 명령 템플릿 snapshot, 각 Attempt에는 치환된 argv를 보존합니다. 환경 오류 후 재개해도 같은 Run의 snapshot을 사용합니다.
- 기존 데이터에 명령 프로파일이 없으면 기존 Mock 기본 명령을 사용합니다. DB 스키마 변경이나 기존 Run 재작성은 없습니다.
- 비밀번호·토큰·SSH 키를 명령 인자로 입력하지 마세요. 명령은 결과 증빙에 포함됩니다. 실제 인증은 승인된 Adapter의 별도 자격증명 처리로 연결합니다. 사내 명령 원본과 설정 DB를 공개 저장소에 올리지 않습니다.
